# ndsc-shell
An amazing shell that lets you control Windows system files faster and easily.

## How to use?
Note: We don't have changing directory command support, but we might have it sooner. For now, you need to write the complete file tree (e.g. "C:\Users\user\Documents\file.txt" instead of "file.txt")

### Commands
**del [file]**

completely remove a file

**rmdir [directory]**

completely remove a directory

**getperms [file/directory]**

gives you permissions to change a file. for the commands listed above, this is not required as it is done automatically. you should only use this for renaming, writing and other actions.
